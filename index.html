      How it works

      Sample size uses the standard two-proportion formula for a two-sided test at the chosen significance and power. With more than two arms, the significance level is split across comparisons against control (Bonferroni), so each variant needs more traffic. Duration is rounded up to whole weeks so every day of the week is represented equally.

      Conversion rate is compared with a two-proportion z-test. Revenue per visitor is compared with a Welch z-test, using the revenue standard deviation per visitor if you supply it, or a conservative estimate if you don't. Both report the relative uplift with a confidence interval.

      Sample ratio mismatch is a chi-square test of observed visitors against the intended even split. At p < 0.001 the assignment is probably broken (bots, redirects, caching or tracking issues), and no result from the test should be trusted.

      Early stopping: checking a test daily and stopping the first time it looks significant inflates false positives well above the nominal rate. If an arm hasn't reached its planned sample, the tool won't call a winner.

      False winners: a variant can raise conversion while lowering order value, or raise engagement while lowering revenue. When conversion and revenue disagree, the tool says so and decides on the primary metric you chose, which should usually be revenue.

      All calculations run in your browser. Nothing is sent anywhere.
